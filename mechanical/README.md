# Tonberry pico cases

## Test rig

The test rig consists of three parts:

The front plate holds the speaker. The mounting holes are for either a Visaton R10 S (or similiar)
speaker, or a small mono speaker https://www.adafruit.com/product/3351 .

The base plate is available in two versions: For the Rev. 1 PCB (the larger PCB with the buttons
mounted directly on the PCB, deprecated), and the Rev. 1.2 PCB plus an optional button board.

The RC522 holder clips onto the top and holds the RC522 NFC reader so that a tag or card can easily
be placed on it.

Besides the 3D printed parts, you need some hardware:

* M3x5x4 heat sink inserts: 8 for the Rev.1 PCB or if you aren't using a button board with the Rev. 1.2, or 12 for a Rev. 1.2 PCB plus button board. 
* M3x6 BHCS (button head) screws to mount the PCB(s): 4 or 8
* M3x8 countersunk screws: 4, to mount the front plate to the base
* M3x12 countersunk screws + M3 nuts: 4, to mount the RC522 to the holder
* For the Visaton speaker: 4x M4x8 countersunk screws + 4x M4 nuts
* For the ADA3351 speaker: 4x M3x? countersunk screws + 4x M3 nuts
